## Direction contract

**Mode: Operate**

THESIS: A field Agent's single working queue across every Contract they
hold, not a per-entity CRUD screen — one Contract-switcher dropdown (never a
tab) scopes Requests, Fleet and Client Invoices, refusing the multi-tab or
multi-page-per-Contract pattern.

OWN-WORLD: Same shared Restrained world as Manager Console — near-white /
near-black canvas, deep-navy ink, one electric-indigo accent on primary stat
numbers and primary actions, hairline borders, self-hosted Inter with
tabular figures, 8px-radius controls, pill shape reserved for Send Invoice /
primary commits. Same rail width and item styling; only the item list
differs.

STORY: An Agent opens on this month's running Local Support Fees, open
Requests, their own Agent Invoice status and standing salary + Rollout
Advance, then scopes into Requests / Fleet / Client Invoices one Contract at
a time via the switcher to act, and separately tracks My Invoice through to
paid.

FIRST VIEWPORT: Left rail (Dashboard / Requests / Fleet / Client Invoices /
My Invoice) at 240px, same styling as Manager Console; four stat cards
(Local Support Fees this month, open Requests, My Invoice status, standing
salary + Rollout Advance); below, a recent-Requests list across both
Contracts linking through to the full Requests queue.

FORM: Brief-pinned direction (Stripe-inspired), no concept-seed roll —
new-work.md's standing rule that a user/brief-pinned direction beats the
roll.

FINISH: unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying
its provenance.
