--- comparison (real-manager-dashboard/spec.md lines ~219-230 vs invoice-adjustment/spec.md) ---
MATCH:    a landed adjustment counts in the invoice it landed on, signed (credit lowers, charge raises); only SENT/APPROVED
          (Client) and APPROVED/PAID (Agent) invoices ever count, so a pending adjustment (which sits on a DRAFT receiving
          invoice) never counts; withdrawn never counts; Client Invoice adjustment lines are stored lines, so the line sum needs no change.
MISMATCH: dashboard spec says an adjustment is "a fifth figure" on an Agent Invoice and that "the Agent side needs the fifth
          figure added to total(ai)". invoice-adjustment/spec.md says "The Agent Invoice gains no new figure": an adjustment moves
          the Agent's Local Support Fees through ContractAmountService.payableAmountForMonth (a SENT Agent Invoice moves in the
          record/withdraw transaction; APPROVED/PAID of an open month moves as month-closes-on-the-fifth makes a line edit move).
          So the shared Agent Invoice total expression would need NO change when invoice-adjustment lands; the dashboard spec's
          claim of a fifth figure is stale. (Also: that moving of an already-APPROVED/PAID Agent Invoice's local-support-fees
          figure is a case the dashboard rule "counts at the total its own page shows" covers, but the dashboard spec does not mention it.)
